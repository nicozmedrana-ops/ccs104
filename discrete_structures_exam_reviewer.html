LESSON 7 • WEEKS 13–14

Binary Trees: the basic idea

A tree is a non-linear data structure made of nodes connected by edges. Unlike an array or linked list, its data branches instead of forming one simple line.

A binary tree is a tree where each node can have at most two children: a left child and a right child. A node may have zero, one, or two children.

8 ← root / \\ 3 10 / \\ \\ 1 6 14 / \\ / 4 7 13

Important terms (easy definitions)

TermMeaningExample in diagram
RootThe top node; there is one root in a non-empty tree.8
ParentA node directly above another node.3 is parent of 1 and 6.
ChildA node directly below another node.10 is a child of 8.
LeafA node with no children.1, 4, 7, 13
SubtreeA node together with its descendants.The branch starting at 3.
PathA sequence of nodes connected by edges.8 → 3 → 6 → 7
LevelGeneration of a node; root is level 0 in the slides.8 level 0; 3 and 10 level 1.
KeyA node value used to search for that node.Searching for key 14.
Visiting / TraversingVisiting checks a node's value; traversing follows a particular order.Reading every node in a chosen order.
Remember: “At most two children” means a node can have 0, 1, or 2 children—not three.
LESSON 7 • TREE TRAVERSAL

Three traversal patterns

Traversal means visiting the nodes in a particular order. For the example below, use this tree:

A / \\ B C / \\ / \\ D E F G
TraversalPatternOutputMemory trick
In-orderLeft → Root → RightD, B, E, A, F, C, GRoot is in the middle.
Pre-orderRoot → Left → RightA, B, D, E, C, F, GRoot comes first.
Post-orderLeft → Right → RootD, E, B, F, G, C, ARoot comes last.

How to solve a traversal question

  1. Start at the root, but do not automatically write it down.
  2. Follow the chosen pattern at every subtree, not just at the whole tree.
  3. Write each node only when its position in the pattern says to visit it.
Common mistake: Pre-order and post-order both visit the left subtree before the right subtree. The difference is where the root is written.

Quick check

For the tree above, which traversal begins with A and ends with G?

Pre-order: A, B, D, E, C, F, G. It starts with the root and then visits left before right.

LESSON 8 • WEEK 15

Finite State Machines (FSM)

A finite state machine is an abstract machine that can be in exactly one state from a finite set of states at a time. It can change state when it receives an input.

StateA condition the machine is currently in.
InputAn event or value the machine receives.
TransitionThe move from one state to another because of an input.
Accept stateA state that represents an accepted/finished condition; often drawn with a double circle.

State transition diagram symbols

  • Circle: a state, often labelled q0, q1, q2, etc.
  • Arrow into a state: may indicate the starting state.
  • Arrow between states: a transition; its label tells which input causes the move.
  • Double circle: an accept state in the heat-wave example.

Example: heat-wave determination

Rule from the slides: a heat wave occurs when the temperature is 45°C or more for 2 consecutive days.

StateMeaningWhat happens next?
q0No qualifying consecutive hot day counted yet.If temperature is at least 45°C, move to q1. If below 45°C, stay/reset to q0.
q1One day at 45°C or more has occurred.If the next day is also at least 45°C, move to q2. If below 45°C, reset to q0.
q2Heat wave has occurred (accept state).Remain in q2 after the event has occurred, as described in the slides.
Example sequence: 46°C, 45°C → q0 → q1 → q2, so the heat-wave condition is met. But 46°C, 40°C resets the count, because the days are not consecutive.

Applications mentioned in the slides

Digital logic design, control systems, natural language processing, and computer networking. The slides also show examples involving a coin-operated turnstile and video game control.

LESSON 8 • REGULAR LANGUAGES

Regular language

A regular language is a language that can be expressed using a finite state machine.

Examples from the lesson

Strings that end with 0

The lesson describes strings with zero or more 1s at the start that end in 0. Examples shown: 0, 10, 1111110.

Strings that end with 1

Examples shown in the slides: 1, 01, 011, 001, 0001111, 01111.

Exam approach

  1. Read the rule carefully: does the string need to start with a symbol or end with one?
  2. Check the last symbol if the rule says “ends with”.
  3. Follow the arrows one input symbol at a time if a state diagram is provided.
  4. At the end, check whether the machine is in an accept state.
Watch out: A string that ends in 0 does not satisfy a rule requiring it to end in 1, and vice versa.
LESSON 9 • WEEKS 16–17

Integer representations / number systems

A number system represents values using a base. The position of each digit determines its place value.

SystemBaseAllowed symbolsQuick note
Decimal100–9Everyday counting system.
Binary20, 1Computers commonly use it; each digit is a bit.
Octal80–7Base 8.
Hexadecimal160–9, A–FA=10, B=11, C=12, D=13, E=14, F=15.

Place value example: decimal 735

735 = 7 × 10² + 3 × 10¹ + 5 × 10⁰

That is 700 + 30 + 5. The rightmost digit is the 10⁰ (ones) place, the next is 10¹ (tens), then 10² (hundreds).

Binary place values

From right to left, the place values are 1, 2, 4, 8, 16, 32, ... (powers of 2).

Example: 1010₂ = 1×8 + 0×4 + 1×2 + 0×1 = 10₁₀.

Where hexadecimal is used

The slides mention memory locations, web-page colors, MAC addresses, and error messages.

LESSON 9 • WORKED EXAMPLES

Conversions and binary arithmetic

1. Decimal to binary: divide by 2

Example: convert decimal 13 to binary. Divide by 2 repeatedly and record each remainder; read remainders from bottom to top.

DivisionRemainder
13 ÷ 2 = 61
6 ÷ 2 = 30
3 ÷ 2 = 11
1 ÷ 2 = 01

Answer: 13₁₀ = 1101₂

2. Binary to decimal: multiply by place values

Example: 1101₂ = 1×8 + 1×4 + 0×2 + 1×1 = 13₁₀.

3. Binary ↔ hexadecimal

For binary to hexadecimal, group bits into sets of four from the right, adding leading zeros if needed. Convert each group to one hex digit.

Example: 1101₂ is one group of four; 1101₂ = 13₁₀ = D₁₆. For hexadecimal to binary, replace each hex digit with its 4-bit equivalent.

4. Binary addition rules

OperationResult
0 + 00
0 + 1 or 1 + 01
1 + 110 (write 0, carry 1)
1 + 1 + carry 111 (write 1, carry 1)

Example: 101₂ + 011₂ = 1000₂ (5 + 3 = 8).

5. One’s and two’s complement

  1. One’s complement: flip every bit (0 becomes 1; 1 becomes 0).
  2. Two’s complement: take the one’s complement, then add 1.

Example using 5 bits: 10010 → one’s complement 01101 → add 1 = 01110.

6. Subtraction using two’s complement

For a subtraction with fixed-width binary values, take the two’s complement of the number being subtracted, add it to the first number, then follow the lesson’s rule for the result.

From the slides: When subtracting a smaller number from a larger number, omit the final carry. When the result is negative (larger number subtracted from smaller number), the result is in two’s-complement form; take its two’s complement to find the magnitude and change the sign. Use the same bit width throughout.

Useful conversion reminders

  • Decimal → binary: divide by 2; read remainders upward.
  • Binary → decimal: add the powers of 2 where the bit is 1.
  • Binary → hex: group into 4 bits from the right.
  • Hex → binary: each hex digit maps to 4 bits.
  • Two’s complement = flip bits + 1.

LAST-MINUTE REVIEW

Answer key & memory shortcuts

Patterns to memorize

  • In-order: Left, Root, Right.
  • Pre-order: Root, Left, Right.
  • Post-order: Left, Right, Root.
  • Binary tree: at most two children per node.
  • FSM: state + input can cause a transition.
  • Regular language: can be expressed by an FSM.
  • Binary: base 2; decimal: base 10; octal: base 8; hexadecimal: base 16.
  • Two’s complement: flip bits, then add 1.
